Usage notes
-------------------------------------------------------------------------------
- Zeko Core is the single distributor of Quill for the whole ecosystem: other
  Zeko modules call Zeko_Core_Assets::enqueue_quill() instead of bundling or
  CDN-loading their own copy, so there is exactly one distributed copy to
  maintain.
- Remote assets: Zeko Core does not load any font, icon, or script from a CDN
  (no Google Fonts, jQuery CDN, etc.). Profile avatars come from WordPress
  core's get_avatar()/Gravatar (a WordPress core feature, browser-side).
- Outbound requests made by Zeko Core are documented in REMOTE-SERVICES.txt in
  this folder.
